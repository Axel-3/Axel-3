# Axel Gutiérrez

Estudiante de Ingeniería en Computación en la UNAM. Construyo apps de principio a fin — base de datos, lógica de negocio y UI — tanto en Android como en web.

## Proyectos

- **[finanzas-app](https://github.com/Axel-3/finanzas-app)** — App Android de finanzas personales: lee notificaciones de banco para registrar gastos e ingresos automáticamente, sin backend. Base de datos cifrada con SQLCipher. Kotlin + Jetpack Compose + Room.
- **[PumasBus](https://github.com/Axel-3/PumasBus)** — Rastreo en tiempo real de los camiones de Ciudad Universitaria sobre mapa. Kotlin + Compose + OSMDroid.
- **[cuponera](https://github.com/Axel-3/cuponera)** — App web de cupones canjeables con panel de administración. Next.js + Supabase + Framer Motion.
- **[Proyecto_distribuidos](https://github.com/Axel-3/Proyecto_distribuidos)** — FutStore, plataforma de e-commerce con arquitectura distribuida (proyecto de equipo, materia de Sistemas Distribuidos).
