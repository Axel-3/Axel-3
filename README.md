## Proyectos

### [finanzas-app](https://github.com/Axel-3/finanzas-app)

App Android para llevar mis finanzas. Lee las notificaciones del banco y registra los gastos sola. Todo se queda en el teléfono, en una base de datos cifrada con SQLCipher.

*Kotlin, Jetpack Compose, Room, Hilt.*

### [PumasBus](https://github.com/Axel-3/PumasBus)

Prototipo de app para seguir los camiones de Ciudad Universitaria en un mapa. Tiene las 13 rutas con sus paradas reales y un simulador que mueve los camiones.

*Kotlin, Jetpack Compose, OSMDroid.*

### [FutStore](https://github.com/Axel-3/Proyecto_distribuidos)

Tienda en línea de playeras de futbol hecha en equipo para Sistemas Distribuidos. Corre en 4 contenedores (Nginx, dos servicios en Flask y PostgreSQL). Yo hice el módulo del carrito.

*Docker, Flask, PostgreSQL.*

### [cuponera](https://github.com/Axel-3/cuponera)

App web de cupones para regalar, con login, roles y panel de administración.

*Next.js, Supabase, Tailwind.*
